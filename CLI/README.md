# koda cli

Cli preta do Koda. Abre uma tela toda preta com a marca Koda centralizada, em degradê roxo, e uma caixa de prompt no rodapé.

## Instalar

```bash
cd CLI
npm link
```

## Usar

```bash
koda
```

ou

```bash
kd
```

Dentro da cli: `help`, `version`, `clear` e `exit` (ou `Ctrl+C`).

Clique nos itens da linha de status (`padrão`, `modelos` e `automático`) para abrir o menu. Dá para escolher com o mouse ou com as setas + Enter; `Esc` fecha o menu. O `Reasoning` também é um botão: clique para acender/apagar o brilho lilás.

No menu de permissão, as opções têm cores: `Plan - Mode` azul, `pergunta sempre` verde, `padrão` laranja, `auto` vermelho e `livre` vermelho escuro. No menu de esforço, `máximo` usa o degradê RGB roxo animado do Koda (lilás, roxo e roxo escuro).
